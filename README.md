# Alex Souza — Consultoria de Negócios e Tecnologia com IA

> **Site Institucional Oficial e Plataforma de Serviços**  
> Engenharia de software ágil, Modern Data Stack, bots inteligentes de atendimento ao cliente 24/7 no WhatsApp, prototipagem rápida de MVPs e consultoria executiva.

---

## 🚀 Stack Tecnológico
- **Frontend:** HTML5 Semântico, CSS3 Moderno (Variáveis de Design System, Dark/Light Mode nativo), JavaScript ES6+
- **Banco de Dados & Leads:** Supabase (PostgreSQL em Nuvem) com tabela `site_contatos_leads` e RLS ativado
- **Deploy & CDN:** Vercel Edge Network
- **Atendimento Integrado:** WhatsApp Oficial & Evolution API

---

## 💻 Como Rodar Localmente
Basta executar:
```bash
python run_server.py
```
O site estará acessível em `http://localhost:5500`.
